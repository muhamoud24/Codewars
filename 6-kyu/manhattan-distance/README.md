<h2><a href=https://www.codewars.com/kata/52998bf8caa22d98b800003a/train/javascript target="_blank">Manhattan Distance</a></h2><h3>6 kyu</h3><p>The distance formula can be used to find the distance between two points. What if we were trying to walk from point <strong>A</strong> to point <strong>B</strong>, but there were buildings in the way? We would need some other formula..but which?</p><h3 id="manhattan-distance">Manhattan Distance</h3><p><a href="http://en.wikipedia.org/wiki/Manhattan_distance" data-turbolinks="false" target="_blank">Manhattan distance</a> is the distance between two points in a grid (like the grid-like street geography of the New York borough of Manhattan) calculated by only taking a vertical and/or horizontal path.</p><p>Complete the function that accepts two points and returns the Manhattan Distance between the two points.</p><p>The points are arrays or tuples containing the <code>x</code> and <code>y</code> coordinate in the grid. You can think of <code>x</code> as the row in the grid, and <code>y</code> as the column.</p><h3 id="examples">Examples</h3><pre><code>* Input [1, 1], [1, 1] =&gt; Output 0* Input [5, 4], [3, 2] =&gt; Output 4* Input [1, 1], [0, 3] =&gt; Output 3</code></pre>
